## The slogan

> Solana never sleeps, so neither does your wallet: it watches, it checks, and it signs only what you approve.

19 words, 108 characters, one line. The wallet as a night watch that never sleeps — a fresh image for Solana's always-on chain — with a plain promise a newcomer gets on one read: nothing gets signed unless you approve it.

## Run

```sh
node main.ts
```

Writes the slogan to `/output/entry.txt`.
